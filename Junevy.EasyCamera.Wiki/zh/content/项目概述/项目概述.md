## 本分类概述

Junevy.EasyCamera 是一个 .NET 工业相机统一操作类库，用一套抽象封装不同品牌的工业相机 SDK，使第三方项目能够快速接入相机能力、通过接口无缝更换相机硬件、并通过 Channel 管理相机帧流。当前版本 1.2.0，海康（HikVision）已可用（含掉线检测与手动重连），华睿（IRayple）未完成、Basler 预留、Cognex 规划中。本分类回答"这个库是干什么的、由什么构成、怎么跑起来、跑之前必须准备什么"四个问题，是第一次接触该仓库时的入口；深入到分层职责、设计模式、帧生命周期与 DI 装配请转到 [[架构设计/架构设计]]。

仓库内的事实来源有三个：`README.md`（现状与推荐用法）、`AGENTS.md`（开发约定与并发纪律）、`CHANGELOG.md`（逐版本变更与验收记录）。三者对同一事实若有冲突，以源码与 CHANGELOG 的最近版本条目为准——README 与 SKILL.md 是面向消费方的说明，可能滞后于实现。

| 关键事实 | 取值 |
|---|---|
| 目标框架 | `net48` + `net8.0`（两个类库与测试工程一致） |
| 运行时位数 | 必须 x64（厂商 SDK 为 AMD64 专用） |
| 消费方入口 | `ICameraService`（业务操作）+ `ICameraSdkSystem`（进程级 SDK 生命周期） |
| 可用品牌 | 海康（基于 `MvCameraControl.Net`） |
| 不可用品牌 | IRayple / Basler：启用即抛 `NotImplementedException` |
| 版本 | 1.1.1（包版本与程序集版本已同步） |
| 厂商托管封装 | 1.1.1 起随 NuGet 包分发（`lib/net48`、`lib/net8.0`） |
| 厂商原生驱动 | 不在包内，需安装 MVS 运行时并保证 `Runtime\Win64_x64` 在 PATH |
| 工程数 | 3（`Core` 契约 / `Junevy.EasyCamera` 实现 / `Tests` 测试） |
| 验收基线 | 全量重建 0 错误 0 警告；net48 与 net8.0 各 149/149 通过（1.2.0 验收修正后） |
